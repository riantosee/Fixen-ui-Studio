# HTML and CSS Guidance

- Use semantic landmarks, headings, lists, forms, and buttons.
- Use CSS custom properties for shared design tokens.
- Prefer grid and flexbox for layout; avoid brittle absolute positioning for primary structure.
- Use responsive constraints such as max-width, minmax, clamp, and intrinsic sizing.
- Define focus-visible styles and reduced-motion alternatives.
- Avoid global selectors that unexpectedly affect unrelated pages.
- Check overflow, stacking contexts, and text wrapping.
- Keep CSS organized by component or feature according to project conventions.
