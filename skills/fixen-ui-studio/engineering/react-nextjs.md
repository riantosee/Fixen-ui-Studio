# React and Next.js Guidance

- Inspect the installed React/Next.js version and router before coding.
- Follow App Router or Pages Router conventions already present.
- Keep server and client component boundaries intentional.
- Add client components only when interaction or browser APIs require them.
- Use framework image, font, and navigation facilities where appropriate.
- Keep data fetching, state, and presentation responsibilities clear.
- Avoid hydration mismatches and unsafe direct DOM manipulation.
- Ensure forms, links, buttons, and dialogs are semantically correct.
- Respect existing styling solution and component library.
- Run available lint, typecheck, build, and relevant tests.
