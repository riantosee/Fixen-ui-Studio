# Tailwind CSS Guidance

- Inspect Tailwind version and project configuration before using utilities.
- Follow existing conventions for class composition and variants.
- Use semantic tokens from the project's theme when available.
- Avoid huge unreadable class strings when a reusable component is justified.
- Do not invent theme tokens that are not configured.
- Use responsive, focus, disabled, and motion variants deliberately.
- Preserve readability and avoid conflicting utilities.
- Prefer project components and design tokens over introducing another UI library.
