# Anti-Generic Design Engine

## Detect generic output
Flag patterns such as:
- Same centered hero + three feature cards + logo strip + FAQ on unrelated products.
- Default purple/blue gradient with no brand rationale.
- Excessive rounded cards and pill buttons.
- Repeated icon-in-colored-circle feature blocks.
- Decorative charts with meaningless data.
- Huge headings that push useful content below the fold.
- Empty whitespace that does not create hierarchy.
- Repeated identical sections and predictable alternation.
- Generic placeholder copy and stock-looking imagery.

## Force product-specific decisions
Before implementation, answer:
1. What is the product's most important user task?
2. What information deserves the strongest visual emphasis?
3. What visual metaphor or motif belongs to this product?
4. What layout best supports the actual content?
5. Which common pattern should be avoided here, and why?

## Variation constraints
Distinctiveness can come from composition, typography, density, imagery, color, interaction, or content—not all at once. Choose a small number of strong differentiators and preserve consistency.

## Final check
If the design could be relabeled for five unrelated businesses without meaningful changes, it is probably too generic.
