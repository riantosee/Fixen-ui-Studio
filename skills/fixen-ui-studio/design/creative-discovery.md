# Creative Discovery

## Brief decomposition
Translate a vague request into:
- Product type and maturity
- Primary user and context of use
- Primary job-to-be-done
- Main user journey
- Primary action and secondary actions
- Information density
- Content and asset needs
- Brand personality
- Technical and delivery constraints

## Exploration
For significant projects, develop 2–3 directions that differ in composition, typographic character, density, surface treatment, and visual metaphor—not merely palette.

For each direction specify:
- Name
- Concept
- Intended emotional response
- Typography approach
- Layout approach
- Color/surface approach
- Signature detail
- Risks and suitability

Choose the best direction based on the product and constraints. Present options if user choice is valuable.
