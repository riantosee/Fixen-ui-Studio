# UX Architecture

## Structure
- Define user roles and context.
- Map the primary journey and likely alternate paths.
- Prioritize information by task frequency, urgency, and consequence.
- Group related information and expose progressive detail.
- Keep navigation labels predictable and task-oriented.
- Make system status and next actions clear.

## Heuristics
Evaluate visibility of system status, match to real-world language, user control, consistency, error prevention, recognition over recall, flexibility, minimalist relevance, error recovery, and help/documentation.

## Forms
Use clear labels, sensible grouping, inline validation, useful error messages, appropriate input types, and explicit success confirmation. Preserve entered data after recoverable errors.

## Dashboards
Prioritize decisions and exceptions, not decorative metrics. Explain units, date ranges, comparison periods, and empty states. Tables should support scanning, sorting, filtering, and responsive alternatives.

## Conversion pages
Make value proposition, proof, offer, and primary action clear. Avoid manipulative urgency, hidden costs, or deceptive interaction.
