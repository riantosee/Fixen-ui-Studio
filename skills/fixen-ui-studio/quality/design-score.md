# Fixen Design Score

Use the canonical rubric in `benchmarks/scoring-rubric.md` (path relative to the skill root). Do not maintain a second weighting system here.

A score is a reviewer judgment over the assessed scope, not proof of production readiness. Report the evidence, evidence coverage, and unassessed dimensions. Core task failures remain failures regardless of aesthetic scores. Do not infer security, performance, accessibility conformance, or integration correctness from a design rating alone.
