# Fixen Design Score

Use a 100-point rubric as an internal comparative aid, not an objective truth.

| Dimension | Weight |
|---|---:|
| Visual hierarchy | 15 |
| Layout and composition | 15 |
| Typography | 12 |
| Color and contrast | 10 |
| Originality and product fit | 12 |
| UX and usability | 12 |
| Responsive behavior | 10 |
| Consistency | 7 |
| Accessibility | 7 |
| **Total** | **100** |

## Rating bands
- 90–100: Excellent candidate; verify all critical states.
- 85–89: Strong, near production-ready.
- 75–84: Useful but needs targeted refinement.
- Below 75: Revisit structure or direction.

## Scoring rules
- Score only dimensions supported by available evidence.
- Mark unavailable dimensions as N/A and normalize the score across assessed weights; disclose coverage.
- Give a short evidence note for each weak dimension.
- Do not let an aesthetic preference outweigh usability or product fit.
- Never fabricate precision. Scores are reviewer judgments, not measured facts.
