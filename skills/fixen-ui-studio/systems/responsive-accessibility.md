# Responsive Design and Accessibility

## Responsive
- Start from content and task constraints, not device labels alone.
- Define behavior at narrow, medium, and wide widths.
- Prevent horizontal overflow except for intentionally scrollable regions.
- Reflow navigation, grids, tables, and media appropriately.
- Preserve hierarchy and task completion on mobile.
- Test long labels, translated content, zoom, and dynamic text where practical.

## Accessibility
- Use semantic landmarks and headings.
- Provide accessible names and labels.
- Ensure keyboard access and visible focus.
- Maintain sufficient contrast.
- Do not rely on color alone.
- Provide text alternatives for meaningful images.
- Associate errors and hints with fields.
- Respect reduced motion.
- Use appropriate table and form semantics.
- Check touch target size and reading order.

Aim for WCAG 2.2 AA as a design target, but do not claim conformance without a suitable audit.
