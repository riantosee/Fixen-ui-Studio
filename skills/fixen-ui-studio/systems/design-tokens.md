# Design Tokens

Create tokens from the selected art direction, not from a generic preset.

## Token groups
- Color: canvas, surface, elevated surface, text, muted text, border, accent, semantic success/warning/danger/info.
- Typography: font families, display/body/label/mono roles, sizes, weights, line heights, letter spacing.
- Spacing: consistent scale with documented exceptions.
- Layout: content widths, columns, gutters, breakpoints.
- Shape: radii, border widths, separators.
- Elevation: shadows and layering only where useful.
- Motion: duration, easing, reduced-motion alternative.

## Rules
- Prefer semantic names over raw color names.
- Check contrast for text and meaningful controls.
- Define dark and light themes only when needed.
- Avoid token proliferation.
- Keep tokens consistent across components.
- Document exceptions and migration strategy.
