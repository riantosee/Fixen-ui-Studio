# Creative Reasoning Protocol

Use these lenses in sequence:

1. **Product truth:** What must the interface help someone accomplish?
2. **Audience:** What knowledge, urgency, trust, and accessibility needs do users have?
3. **Brand character:** Which visual qualities express the product credibly?
4. **Differentiation:** What is one memorable, useful visual idea?
5. **Usability:** Does the visual idea strengthen or obstruct comprehension?
6. **Feasibility:** Can the chosen direction be implemented in the current stack?
7. **Validation:** What observable evidence will show that the result works?

Reject novelty that harms clarity. Reject generic convention when a more fitting solution is available. Explain consequential trade-offs briefly.
