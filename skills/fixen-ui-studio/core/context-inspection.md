# Project and Context Inspection

## Existing repository
Before editing:
- Identify project root and relevant app entry points.
- Read package/build configuration and framework version.
- Inspect routing, layout, styling strategy, component library, assets, and design tokens.
- Locate the target page and nearby shared components.
- Check current git diff or equivalent workspace state when available; do not overwrite user work.
- Run or inspect existing tests/build commands where useful.

## User brief
Extract audience, task, product category, brand attributes, content, conversion goal, required features, constraints, and success criteria.

## Reference analysis
For each supplied reference, describe:
- Composition and visual hierarchy
- Typography roles and scale
- Color relationships and contrast
- Spacing rhythm and density
- Surface, border, and shape language
- Interaction cues and states
- Distinctive motifs

Separate observed facts from interpretation. Do not infer hidden implementation details from a screenshot.

## Output
Create a compact context summary. Ask only for a missing decision that cannot be safely inferred and materially changes the outcome.
