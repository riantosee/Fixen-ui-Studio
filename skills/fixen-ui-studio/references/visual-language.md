# Visual Language Reference

## Hierarchy
Use size, weight, contrast, position, spacing, and grouping to establish priority. Do not rely on size alone.

## Spacing
Create a rhythm with a small, coherent scale. Use larger gaps to separate conceptual groups and smaller gaps within related controls.

## Typography
Use a limited set of roles. Keep body copy comfortable to read. Avoid long all-caps passages and excessively thin text.

## Color
Use semantic roles and ensure text/control contrast. Color should reinforce hierarchy and meaning, not merely decorate.

## Imagery
Select imagery that supports the product story. Maintain consistent crop, aspect ratio, and treatment. Avoid random stock imagery.

## Density
Match information density to task frequency and user expertise. Dense interfaces still need grouping, alignment, and clear scanning paths.
